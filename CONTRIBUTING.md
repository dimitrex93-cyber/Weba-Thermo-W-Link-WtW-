# Beitragende (Contributing)

Danke, dass du dieses Projekt verbessern möchtest! So kannst du mitwirken:

## Wie du helfen kannst

1. **Issues melden** – Fehler oder Verbesserungsideen als GitHub-Issue anlegen.
   Nutze dafür die vorbereiteten Vorlagen (Bug-Report / Feature-Wunsch).
2. **Pull Requests** – Code, Doku oder Build-Verbesserungen als PR einreichen.
3. **Testen & Feedback** – Hardware-Kombinationen, die du ausprobiert hast, im
   Issue/Discussions teilen.

## Workflow für Pull Requests

1. Repo forken (Button oben rechts auf GitHub).
2. Eigenen Branch anlegen: `git checkout -b mein-feature`
3. Änderungen committen und pushen: `git push origin mein-feature`
4. Auf GitHub einen Pull Request gegen den `main`-Branch öffnen.
5. Die PR-Vorlage ausfüllen (Beschreibung, Test, Checkliste).

## Regeln

- **Eine Änderung pro PR** – so ist Review einfacher.
- **Keine Geheimnisse einchecken** – keine Passwörter, API-Keys oder
  WLAN-Credentials in Dateien oder Commits (auch nicht in alten Commits).
- **Doku mitpflegen** – wenn sich Verhalten/Pins ändern, README aktualisieren.
- **Formatierung** – am Code-Stil des Projekts orientieren (siehe platformio.ini
  bzw. bestehenden Code).

## Lizenz

Durch das Einreichen eines PRs stimmst du zu, deine Änderungen unter der
MIT-Lizenz des Projekts zu veröffentlichen.
